## 📝 계획 요약
- **전체 스킬 검토**: `skills/`의 스킬을 하나씩 열어 발동 조건과 본문을 확인하고, 그 자리에서 고친다.
- 스킬 종류는 이름 앞부분으로 나눈다: `show-`(결과물 표현), `workflow-`(워크플로우), 없음(작업 방법).
- 검토 기준

| 확인할 것 | 기준 |
| --- | --- |
| 발동 조건 | 언제 쓰는지가 예시 요청과 함께 분명하고, 다른 스킬과 겹치지 않는다 |
| 본문 | 발동 조건이 약속한 것만 다루고, 예시로 보이는 설명과 중복 구절이 없다 |
| 부품 연결 | 링크는 위에서 아래로만 둔다. 같은 원칙을 두 곳에 쓰지 않는다 |
| 참조 파일 | references·assets·agents 파일이 본문과 맞고, 본문에서 링크된다 |

- 범위 밖: `plugins/`(스킬이 아님). Codex 설치본 갱신은 전체 계획 '남은 계획'으로 넘긴다.
