# change-report

Claude Code의 응답 바로 밑에 그 턴에서 추가·수정·삭제된 파일을 접히는 카드로 붙여 주는 모드입니다.

```
╭───────────────────────────────────────╮
│ ▾ 변경 파일  +2  ~1  −1                │   ← 누르면 열고 닫힘 (기본: 닫힘)
│ + docs/plan.md  +12                   │   초록
│ + sample.txt  +2                      │   초록
│ ~ hooks/register.tsx  +8 −3           │   노랑
│ − old.txt  −40                        │   빨강
╰───────────────────────────────────────╯
```

- **토큰 0**: 도구 호출을 지켜보며 기록만 하고 모델을 부르지 않습니다. 카드는 대화 기록에 들어가지 않습니다.
- **Claude Code 전용**: Codex는 이 폴더를 읽지 않습니다.
- **저장소가 아니어도 동작**: git diff가 아니라 도구 호출을 기준으로 기록합니다.
- **모양**: 고정폭 작은 글씨의 테두리 카드입니다. 색은 테마의 diff 색(`diffAdded`, `diffRemoved`)과 `warning`을 따릅니다. 터미널에서는 글씨 크기와 글꼴 설정이 무시되고 색과 테두리만 적용됩니다.
- **열고 닫기**: 머리줄을 누르면 응답마다 따로 펼치고 접습니다. 상태는 세션 동안 유지됩니다.
- **경로**: 작업 폴더 안이면 상대 경로, 밖이면 절대 경로입니다. 폴더는 끝에 `/`를 붙입니다.
- **합치기**: 같은 파일이 한 턴에 여러 번 바뀌면 처음과 마지막 상태로 합치고 줄 수는 더합니다. 새로 만들고 지운 파일은 표시하지 않고, 지우고 다시 만든 파일은 수정으로 표시합니다.
- 서브에이전트가 바꾼 파일도 메인 응답에 함께 표시합니다. 변경이 없는 턴에는 아무것도 붙이지 않습니다.

## 감지 범위

| 도구 | 종류 | 줄 수 |
| --- | --- | --- |
| Write | 실행 전에 파일이 있었으면 수정, 없었으면 추가 | 도구 결과의 diff (새 파일은 전체 줄 수) |
| Edit | 수정 | 도구 결과의 diff |
| NotebookEdit | 수정 | 셀 원본의 줄 단위 비교 (근사치) |
| Bash, PowerShell | `rm`, `rmdir`, `del`, `erase`, `rd`, `Remove-Item`, `ri`, `git rm`의 대상이 실행 후 없어졌으면 삭제 | 지우기 직전에 읽은 줄 수 (폴더, 바이너리, 4MiB 초과 파일은 생략) |

셸 명령으로 만들거나 고친 파일, 이동(`mv`, `Move-Item`), 와일드카드·변수를 쓴 삭제, 스크립트 안에서 바뀐 파일은 감지하지 않습니다.

최대 표시 줄 수 등은 `hooks/register.tsx` 맨 위의 `CONFIG`에서 바꿀 수 있습니다.
