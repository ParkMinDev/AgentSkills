# turn-meter

Claude Code의 응답 바로 밑에 그 턴의 토큰 사용량을 흐린 줄로 그려 주는 모드입니다. 이 세션의 평소 값과 비교해 크게 달라진 항목이 있으면 advisor 줄도 함께 보여 줍니다.

```
입력 12.3만 (읽기 횟수 3, 캐시적중 12%, 변동 +8.3만, +208%)
출력 1,100 (변동 +815, +286%)
입출력 12.4만 (변동 +8.4만, +209%)
마지막응답으로부터 9분 · 응답 소요시간 48초 · 서브에이전트 2개 · 컴팩트횟수 1
🔴 [캐시적중 하락] 평소 97% → 12% · 대기 9분 (수명 5분)
🟡 [대화 급증] 3.1만 → 6만 · 평소 +2,000
```

- **토큰 0**: 엔진이 이미 가진 숫자로 계산하고 모델을 부르지 않습니다. 그린 줄은 대화 기록에 들어가지 않습니다.
- **요약 4줄**:
  1. 입력: 총량(메인 + 서브에이전트, 캐시 포함), 읽기 횟수(메인 대화의 모델 호출 수), 캐시적중, 직전 턴 대비 변동(차이, 비율)
  2. 출력: 총량과 직전 턴 대비 변동
  3. 입출력: 입력 + 출력과 직전 턴 대비 변동
  4. 마지막 응답 이후 지난 시간, 응답 소요시간, 서브에이전트 수(쓴 턴만), 컴팩트횟수(1회 이상일 때만)
- **변동**: 직전 턴 값이 없으면 생략합니다.
- **advisor**: 직전 5턴(컴팩트 턴 제외)의 중앙값과 비교해 변동을 감지합니다. 기록이 3턴 미만이면 쉽니다. 최대 4줄, 🔴 → 🟡 → ℹ️ 순서입니다.

| 규칙 | 감지 조건 |
| --- | --- |
| 컴팩트 | 이번 턴에 컴팩트 발생 |
| 캐시적중 하락 | 평소보다 30%p 이상 하락 (대기 시간이 캐시 수명을 넘었으면 함께 표시) |
| 대화 급증 | 대화 증가량이 평소의 3배 이상, 최소 +1만 |
| 입력 급증 | 입력 총량이 평소의 2배 이상, 최소 5만 |
| 요청 급증 | 모델 요청 횟수가 평소의 2배 이상, 최소 +5회 |
| 출력 급증 | 출력이 평소의 3배 이상, 최소 2,000 |
| 서브에이전트 급증 | 개수가 평소보다 많고 토큰이 평소의 2배 이상, 최소 1만 |

기준값은 `hooks/register.tsx` 맨 위의 `CONFIG`에서 바꿀 수 있습니다.
