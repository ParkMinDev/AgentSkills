# Obsidian 문서 자료 정리

- 문서 전용 이미지·첨부·표 원본은 문서 옆의 `<확장자를 뺀 문서명>.Data/`에 둔다. 하위 문서가 자체 자료를 가지면 같은 규칙을 적용한다. 예를 들어 `기획서.Data/레시피 표.base`의 메뉴 원본은 `기획서.Data/레시피 표.Data/Menus/`에 둔다.
- 자료의 이름·수정·보관을 어느 문서가 결정하는지 기준으로 소속을 정한다. 다른 노트에서 링크해도 전용 자료일 수 있다. 여러 문서가 독립적으로 관리하는 공용 자료는 제자리에 둔다.
- 새 자료는 처음부터 해당 위치에 둔다. 이동·개명은 요청 범위에서 처리하고 위키 링크·임베드·상대 Markdown 링크·Canvas 파일 노드·Base 경로 필터를 새 위치에 맞춘다. 링크의 별칭과 섹션·노드 ID는 유지한다.
