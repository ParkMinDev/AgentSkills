# Obsidian 문서 자료 정리

- **기본 위치**: 문서 전용 이미지·첨부·표 원본은 문서 옆의 `<확장자를 뺀 문서명>.Data/`에 처음부터 둔다. 새 Canvas·Base는 자료가 비어 있어도 이 폴더를 기본으로 만든다. 하위 문서에도 같은 규칙을 적용한다.
- **Base 원본**: 원본을 따로 지정하지 않으면 Base가 자기 `.Data/`의 Markdown 노트를 읽도록 필터를 설정한다. 지정된 기존 원본은 원래 위치에서 참조한다. 테스트용 Base가 자체 원본을 쓰면 샘플 노트 하나를 넣는다.
- **자료 소속**: 자료의 이름·수정·보관을 관리하는 문서를 기준으로 전용 여부를 정한다. 다른 노트에서도 링크하는 전용 자료는 해당 문서에 두고, 여러 문서가 독립적으로 관리하는 공용 자료는 제자리에 둔다.
- **경로 변경**: 요청 범위에서 자료를 이동·개명하고 위키 링크, 임베드, 상대 Markdown 링크, Canvas 파일 노드, Base 경로 필터를 갱신한다. 링크 별칭, 섹션·노드 ID는 유지한다. 읽기나 본문 편집만 요청한 경우 자료 위치는 그대로 둔다.
