# 변경 비교 표시

표기는 아래 예시를 따른다. 예시는 표현 방식만 보여 주며, 어떤 형식의 결과물에도 같은 방식으로 쓴다.

## 예시

```diff
  회의 준비
  1. 안건 정리
- 2. 자료 인쇄
+ 2. 자료 공유 링크 만들기
+ 3. 회의실 예약
- 3. 참석자 연락
+ 4. 참석자 연락
- 4. 간식 준비
  …
  끝나면 회의록 정리
```

## 규칙
- **기준은 현재 상태다.** 현재 내용을 실제로 확인하고, 그 위에 바뀌는 줄만 표시한다. 새 모습 전체만 보여 주고 차이를 독자가 찾게 하지 않는다.
- **대상을 밝힌다**: 블록 위에 무엇의 내용인지(파일 경로 등)를 쓴다. 비밀번호·키·토큰은 실제 값을 쓰지 않고 `<토큰>`처럼 자리표시로 둔다.
- **줄 맨 앞 표시**: `+` 추가, `-` 삭제, 공백 한 칸은 그대로다. 수정은 `-` 이전 줄 바로 아래에 `+` 새 줄을 둔다. 번호·구분 기호·들여쓰기 기호처럼 형식 때문에 바뀌는 줄도 짝으로 표시한다.
- **색은 `diff` 코드 블록에 맡긴다.** 채팅과 Obsidian 모두 `+`줄을 초록, `-`줄을 빨강으로 칠한다. 색 문법이나 HTML을 직접 쓰지 않는다.
- **접기**: 바뀌지 않는 큰 덩어리는 펼치지 않고 `…` 한 줄로 접는다. 바뀐 줄의 위치를 알 수 있을 만큼 앞뒤 줄은 남긴다.
- **설명**: 줄 끝 설명은 필요한 줄에만 붙인다. `+`/`-`가 이미 추가·삭제를 말하므로 "새", "삭제" 같은 말을 반복하지 않는다.
- **전체가 새것이거나 전체가 없어지면** diff로 감싸지 않는다. 새 것은 그 형식의 코드 블록으로 보여 주고, 없어지는 것은 이름과 이유를 한 줄로 쓴다.
- 위치가 여러 곳이면 블록을 나누고 소제목을 단다. 블록으로 담지 못하는 규칙(언제 생기는지 등)은 블록 아래 짧게 적는다.
- **Obsidian 문서에 쓸 때**: diff 블록을 `> [!quote]+ 변경 비교` 콜아웃(펼침)에 넣고, 바로 아래에 같은 대상의 완성본을 `> [!quote]- 완성본` 콜아웃(접힘)으로 둔다. 콜아웃 안의 모든 줄 앞에 `> `를 붙인다. 채팅에서는 콜아웃이 접히지 않으므로 diff만 보여 준다.
